# M4 — Reversal-zone gating (skipped-window as timing gate) — FINDINGS

id: momentum_enh_M4_reversal_gate
date: 2026-07-31
mechanism: M4 (momentum enhancement batch)
hypothesis: >
  Momentum forward-return depends on the sign/magnitude of the SKIPPED 21-day
  window (t-21->t, the piece the baseline discards): a mild pullback into an
  intact trend may beat a recent spike. India sign UNKNOWN a priori — directional
  estimation, NOT confirmation. A null (interaction ~ 0) is a valid result meaning
  the baseline was correct to discard the window.
category: momentum / microstructure / timing
mechanism_tags: reversal, skip_window, timing_gate, interaction, fama_macbeth,
  short_term_reversal

data_and_universe: >
  Nifty 500 PIT universe, v3 panel (feature_panel_with_pit_v2, 3,328,132 rows,
  2010-2026). PIT filter in_nifty500_flag == 1. 8 corp-action tickers screened.
  signal = frozen 12-1 momentum over [t-252, t-21] (232 rows, vendor-failure
  adjusted); gate = skipped-window return over (t-21, t]; forward = return over
  (t, t+N]. Controls: Amihud (monthly) + trailing turnover, both z-scored.
  Regressors z-scored cross-sectionally each month; Newey-West SEs (6-month lag)
  on the Fama-MacBeth coefficient series. 179 months.

test_design: >
  HEADLINE = Fama-MacBeth cross-sectional regression of forward return on
  [z(momentum), z(gate), z(momentum)*z(gate)] + z(Amihud) + z(turnover). The
  INTERACTION coefficient's NW t-stat is the result. Double-sort is illustration
  only (never promoted). Gate forms: raw (HEADLINE), vol-standardized, sign-only
  (interpretation aids). Horizons: N=21 (primary), N=63 (robustness).
  PRE-REGISTERED LOCK: raw gate @ N=21 is THE headline regardless of how the
  interpretation aids land. Two-boundary leak check passed (signal | gate |
  forward abut without overlap; gate ends exactly at t).

result: >
  DECISION: REJECT on a clean NULL. Headline (raw gate @ N=21): interaction coef
  0.00107, NW t=1.91 — BELOW the pre-registered t>2 bar. The skipped 21-day
  window does NOT carry reliable timing information for Indian momentum.
  Momentum coef itself is healthy (0.00456, t=3.59); the standalone gate coef is
  null (-0.00066, t=-0.84). It is specifically the INTERACTION that is absent.

  Interpretation aids (subordinate; DO NOT change the verdict):
    raw @21 (HEADLINE)     coef 0.00107  t=1.91  ns
    vol-standardized @21   coef 0.00135  t=2.04  SIG (marginal — see below)
    sign-only @21          coef 0.00032  t=0.54  ns
    raw @63 (robustness)   coef 0.00097  t=0.80  ns

  THE vol-standardized t=2.04 IS TREATED AS NOISE, NOT A SIGNAL. Reasoning,
  recorded so it is dismissed on evidence not convenience: (1) four gate forms
  were tested; one crossing t=2 barely (2.04) is exactly what multiple testing
  predicts — promoting it would give four chances at the bar instead of one,
  the error the pre-registration exists to prevent; (2) t=2.04 on 179 months is
  marginal, and at 18 cumulative trials it almost certainly fails a DSR haircut;
  (3) the pattern is INCOHERENT for a real effect — a genuine gate signal would
  not appear in ONLY the vol-standardized form while sign-only (t=0.54) and
  N=63 (t=0.80) are dead flat and no liquidity tercile clears t=1.4. Scattered,
  isolated marginal significance is the signature of noise, not a hidden effect.

tercile_split: >
  No liquidity tercile clears significance (T1 illiq t=0.34, T2 mid t=1.39,
  T3 liq t=1.21). Unlike M3, there is NO 'effect hiding in illiquid names' story
  — the interaction is weakly and UNIFORMLY absent across liquidity. Clean.

double_sort_illustration: >
  (Picture only, not a claim.) Mean forward-21d return by corner: high-momentum
  pullback 1.73% vs high-momentum spike 1.56% (US-reversal direction), low-mom
  pullback 1.15% vs spike 0.95%. The ~0.17pp high-mom gap LOOKS mildly
  suggestive but the FM regression that properly tests it is not significant —
  exactly why the double-sort was pre-declared illustration only.

turnover: >
  Gating (hold top-decile momentum only where gate is favorable) adds +26.3pp of
  monthly turnover (29.8% -> 56.1%). Even had the effect been real, this churn
  plus the M1 tax/cost lesson makes a marginal gross gate untradeable. The null
  is near-moot on tradeability grounds regardless.

validation_summary: >
  leak check: signal ends t-21, gate (t-21,t], forward (t,t+N] — abut without
    overlap; gate ends exactly at t (probe 3IINFOLTD 2018-04-30). PASS.
  coverage: gate valid on 100% of eligible names (derivable from existing
    returns). PASS.
  sign-flip: gate takes both signs, matches recent-return direction. PASS.
  gate != signal: cross-sectional corr(momentum, gate) = 0.039 (distinct
    windows). PASS.
  detection power (pre-run): FM regression recovers a planted +0.8 interaction
    as 0.801 (t=78) and -0.6 as -0.599 (t=-59) — so this null is a TRUE null,
    not a blind machine. Both signs, exact magnitude.

holdout_status: not tested (null on full sample; hold-out not triggered)

decision: REJECT (clean null — skipped window carries no recoverable timing info)

insight: >
  In India, the 21-day window the baseline discards is genuinely uninformative as
  a momentum timing gate — the baseline's design choice to skip it is vindicated,
  not merely tolerated. Short-term reversal-vs-continuation does NOT interact with
  the 12-month trend in a way that survives rigorous cross-sectional testing. The
  one marginal hit (vol-standardized gate, t=2.04) is best explained as the
  expected false positive from testing four gate forms, not a real effect — it is
  isolated, barely over the bar, and unsupported by every other cut (sign-only,
  N=63, all terciles). A cleanly-closed 'no' is more valuable than a fragile
  'maybe' promoted on one lucky transformation.

incidental_observations: >
  (1) The double-sort's high-momentum pullback>spike ordering is in the
  US-textbook reversal direction but too weak to be significant — consistent with
  'the US effect exists directionally in India but is not strong/robust enough to
  trade,' which matches the broader finding that Indian short-term reversal is
  weak. (2) The vol-standardized form being the ONLY one to (marginally) cross
  the bar is a clean illustration of why pre-registering the headline matters:
  without the lock, this run would have produced a 'significant' result. Worth
  remembering as a methodological exemplar. (3) Momentum's own coefficient
  (t=3.59) reconfirms the baseline signal is intact on this fresh FM setup —
  a free integrity check on the 12-1 signal.

flag_for_idea_generator: >
